# ZerØ Target — ZerØ Network

Registro público de versiones y documentación de `zero_target`.

Versión actual: **1.0.1**. Target ajustado para suplir `ox_target`, `qb-target` y `qtarget` utilizando `provide` de cada uno para su ejecución óptima en ZerØ Network.

Este repositorio contiene únicamente documentación pública y metadatos de versión para la comprobación automática de actualizaciones del recurso. El script se distribuye cifrado mediante Cfx.re Asset Escrow.

---

### 🚀 Novedades de la Versión 1.0.1
- **Persistencia Multinivel Instantánea:** Los cambios realizados por los jugadores en `/targetmenu` (modo de activación, color de acento, tipografía y forma geométrica) se guardan al instante en tiempo real en la NUI, en el KVP local del cliente y en el almacén del servidor por licencia de FiveM.
- **Forma Inicial Configurable:** Se expone `Config.UI.Shape` en `shared/config.lua` para que los administradores del servidor puedan definir la forma con la que inician los nuevos jugadores (`diamond` / Rombo, `circle` / Círculo, `square` / Cuadrado).
- **Faros 3D de Proximidad Inteligentes:** Filtrado optimizado de entidades para evitar puntos de proximidad flotantes sobre objetos globales del mapa (como cerraduras globales de puertas).
- **Estética Refinada ZerØ:** Eliminación de matices rojizos fijos en las opciones y previsualización en vivo, incorporando resplandores difusos basados en el color de acento dinámico elegido.
- **Compatibilidad Total Verificada:** Probado y balanceado al 100% en QBCore, Qbox y ESX Legacy a 0.00ms en reposo.
